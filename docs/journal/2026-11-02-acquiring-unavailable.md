# 2 ноября 2026 — эквайринг недоступен самозанятому

## Что случилось

Банк-эквайрер ответил: проект можно рассмотреть только при подключении как юрлицо или ИП. Как самозанятый — только другой проект.

## Следствия

- Подключение интернет-эквайринга для Сборной как самозанятого невозможно.
- Варианты:
  1. Платёжный сервис с тарифом для самозанятых: подключение 0 ₽, комиссия за карты и СБП, платёжные ссылки/QR, автоматические чеки.
  2. Зарегистрировать ИП и вернуться к эквайрингу.
  3. Ручной приём СБП/QR с чеком в «Мой налог».
- Презентация: строка про эквайринг заменена на строку про оплату по СБП.
- `PAYMENT_URL` в боте остаётся пустым.

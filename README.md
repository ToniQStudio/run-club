# Беговой клуб — проект

Рабочая папка проекта. Рабочее название — **ЮБ800**, беговой клуб Юрия Борзаковского.

## Статус

Собран компактный план под масштаб 50–80 участников, бюджет до 300 тыс. ₽. Первая открытая пробежка — 21 ноября 2026, платные группы — с декабря. Лендинг готов как прототип: осталось подключить Telegram-бота, домен, фотографии и юрлицо.

## Репозиторий

Репозиторий **приватный**. Сайт не опубликован: GitHub Pages, Vercel и другие публичные деплои не подключены. Для локального просмотра — `cd landing && npm run dev` (http://localhost:4173). Сырые исходники фото и папка `.shots` в репозиторий не входят.

## Кто в проекте

- **Звезда** — Юрий Борзаковский: олимпийский чемпион Афин-2004 на 800 м, чемпион мира в помещении, 12-кратный чемпион России, экс-главный тренер сборной России по лёгкой атлетике (2015–2021), спортивный директор ВФЛА. Круг 10–20 тёплых контактов. Лицо, методология, 1–2 тренировки в месяц, премиум.
- **Директор** — в прошлом чемпион России по лёгкой атлетике, умеет строить цифровые продукты. Операционка, продажи, продукт, экономика.
- **Тренеры** — призёры и чемпионы России. Пока готовность на словах; на старт нужно 2 подтверждённых.

## Экономика в одном экране

| Показатель | Значение |
|---|---|
| Выручка года 1 | 7,78 млн ₽ |
| Прибыль года 1 | 3,28 млн ₽ |
| Окупаемость | март 2027 |
| Безубыточность без директора | 8–10 участников |
| Безубыточность с директором | 23–25 участников |

Это базовый сценарий. Пессимистичный — 45 участников и 0,8–1,0 млн ₽ прибыли. Главный риск не деньги, а спрос и время звезды.

## Ближайшие шаги

1. Согласовать и подписать соглашение с Борзаковским до 14 ноября.
2. Зарегистрировать ИП/ООО и подключить оплату.
3. Забронировать зал и согласовать точку сбора на набережной Лужников.
4. Подтвердить двух тренеров.
5. Утвердить ЮБ800, создать клубного Telegram-бота (регистрация/оплата) и подключить домен.
6. Сделать съёмку и запустить предпродажи.
7. Провести первую открытую пробежку 21 ноября.

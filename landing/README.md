# Лендинг ЮБ800

Статическая страница клуба с формой записи на пробежку. Без фреймворков и внешних зависимостей: шрифт и картинки лежат локально. Заявки уходят в единый Lead Intake API (`crm/`), токены CRM/Telegram не попадают в браузер.

## Файлы

```
index.html          — главная
privacy.html        — политика обработки ПДн (черновик)
styles.css          — стили и токены
script.js           — валидация формы и отправка
api/lead.js         — серверный обработчик для Vercel
dev-server.mjs      — локальный сервер с мок-API
assets/             — favicon, OG-картинка, hero-фото, логотип, шрифт Jost
```

## Локальный запуск

```bash
cd landing
npm run dev
```

Откройте `http://localhost:4173`. Форма работает в mock-режиме: заявка никуда не уходит, но показывает успех. Это нужно, чтобы проверять валидацию и состояния.

## Продакшен

Деплой на Vercel: корень проекта — папка `landing`. Vercel подхватит `index.html` и `api/lead.js`.

Переменные окружения:

| Переменная | Где взять |
|---|---|
| `TELEGRAM_BOT_TOKEN` | @BotFather → новый бот → токен |
| `TELEGRAM_CHAT_ID` | @userinfobot или `getUpdates` после сообщения боту |

Бот должен иметь доступ к чату, куда будут падать заявки. Токен хранится только в переменных окружения Vercel. Не вставляйте его в `script.js` или HTML.

### Проверка формы

1. Отправьте тестовую заявку.
2. Убедитесь, что сообщение пришло в Telegram.
3. Проверьте ошибку: отключите интернет и отправьте снова — должно появиться сообщение об ошибке.
4. Проверьте honeypot: заполните скрытое поле через DevTools — заявка не должна уйти.

## Что сделать перед публикацией

1. Зарегистрировать домен `yb800.ru` (и `yb-800.ru` как резерв).
2. Заменить черновик политики ПДн на документ, согласованный с юристом.
3. Добавить реквизиты ИП/ООО в футер.
4. Сделать съёмку с Борзаковским и добавить фото.
5. Подтвердить имена тренеров.
6. Подключить Яндекс.Метрику и цели на `form_submit` (сейчас аналитики нет).
7. Проверить, что Telegram-бот и чат настроены.
8. Обновить `og:image` и canonical после запуска домена.
9. Утвердить правила пропусков, заморозки и возврата — сейчас это черновик.
10. Подтвердить права на фото hero (`bg.jpg` → `assets/hero-card-16x9.jpg` / `hero-card-4x3.jpg`) и фон `bg5` для коммерческого использования.

## Дизайн

- База: графит `#030712`, текст `#f9fafb`, лайм `#ccff00` для действий.
- Типографика: **Jost** (variable, self-hosted, OFL) — геометрический гротеск. В логотипе ЮБ набраны Jost 700, 800 — по геометрии Futura. Один файл `assets/fonts/jost.woff2`; лицензия — `assets/fonts/OFL.txt`.
- Track blue `#1e5aa8` — декоративные дорожки: lane divider и карта Лужников.
- Карта: полная дорожка со стартовой линией и номерами 1–8.
- Lane divider: стартовая полоса на 8 дорожек.
- Все цвета, отступы и размеры — в `:root` в `styles.css`.
- Графика — inline SVG; hero-фото — `assets/hero-card-16x9.webp` / `hero-card-4x3.webp` (JPEG-фолбэк); фон секций «Под вашу цель» и «Кто будет рядом» — `assets/bg5.svg` (векторная дорожка, по ширине окна, с плавным затуханием).
- Hero — фото на всю ширину окна: 16:9 на десктопе, высота ограничена первым экраном; 4:3 на планшете/мобильном, текст ниже. Изображение `object-fit: cover` с `object-position: top`, чтобы не резать голову; градиента нет, тексты hero — белые с лёгкой тенью.
- Логотип в шапке — `assets/logo-wordmark-dark.svg` цвета лайм: ЮБ — Jost 700, как монограмма в блоке «Команда»; 800 — прежняя Futura-геометрия. Высота в шапке — 14/16 px. Favicon — `assets/favicon.svg` с «800».

## Заявки

С 22 октября 2026 форма отправляет заявку не в `/api/lead`, а в единый intake `crm/`:

- локальный адрес — `http://localhost:4174/api/leads` (задан в `data-endpoint` формы);
- запуск: `cd ../crm && cp .env.example .env && npm run dev`;
- для production заменить `data-endpoint` на адрес intake в РФ;
- `api/lead.js` оставлен как legacy и формой не используется;
- данные пользователей не должны приниматься Vercel-функцией.

# Подключение Telegram-бота к форме

Цель: заявки с лендинга приходят в закрытый чат или канал клуба. Токен бота хранится только в переменных окружения, не в коде страницы.

## 1. Создать бота

1. Откройте @BotFather в Telegram.
2. Команда `/newbot`.
3. Имя: `YB800 Leads` (или любое).
4. Username: например `yb800_leads_bot`.
5. BotFather выдаст токен вида `123456789:AA...`.

Токен — секрет. Не отправляйте его в чаты и не вставляйте в HTML.

## 2. Создать чат для заявок

1. Создайте закрытый канал или группу, например «ЮБ800 — заявки».
2. Добавьте бота в администраторы.
3. Напишите в чат любое сообщение — это нужно, чтобы Telegram показал `chat_id`.

Для канала удобнее отдельный закрытый канал: заявки не теряются в личных сообщениях.

## 3. Получить chat_id

Откройте в браузере:

```
https://api.telegram.org/bot<ТОКЕН>/getUpdates
```

Найдите в ответе:

```json
"chat": {
  "id": -1001234567890,
  "title": "ЮБ800 — заявки",
  "type": "channel"
}
```

`chat_id` — это число. Для канала оно начинается с `-100`, для группы тоже отрицательное, для личного чата — положительное.

Если `getUpdates` пустой: напишите боту в чат ещё раз и обновите страницу. Для канала убедитесь, что бот добавлен и у него есть право публиковать сообщения.

## 4. Проверить отправку

```bash
curl "https://api.telegram.org/bot<ТОКЕН>/sendMessage" \
  -d chat_id=<CHAT_ID> \
  -d text="Тестовая заявка ЮБ800"
```

Если сообщение пришло — всё настроено.

## 5. Добавить переменные в Vercel

В проекте Vercel:

1. Settings → Environment Variables.
2. Добавьте:
   - `TELEGRAM_BOT_TOKEN` — токен из BotFather.
   - `TELEGRAM_CHAT_ID` — число из `getUpdates`.
3. Environment: Production и Preview.
4. Redeploy.

Локально можно создать `.env` по образцу `.env.example`, но не коммитить его.

## 6. Проверить форму

1. Откройте лендинг.
2. Отправьте тестовую заявку.
3. Проверьте сообщение в Telegram.
4. Отправьте заявку без согласия — должна быть ошибка.
5. Заполните скрытое поле `company` через DevTools — заявка не должна уйти.

## 7. Ошибки

| Ответ | Причина | Что делать |
|---|---|---|
| 401 Unauthorized | Неверный токен | Проверить токен, перевыпустить у BotFather |
| 400 chat not found | Неверный chat_id или бот не в чате | Добавить бота, получить id заново |
| 403 Forbidden | Бот не админ канала | Выдать права администратора |
| 429 Too Many Requests | Слишком много сообщений | Подождать, проверить циклы отправки |

## 8. Безопасность

- Токен — только в переменных окружения Vercel.
- Не логировать токен и данные заявок.
- При утечке — `/revoke` у BotFather и новый токен.
- Не добавлять бота в публичные чаты.
- Ограничить права бота: только публикация сообщений.

## 9. Локальный режим

```bash
cd landing
MOCK_TELEGRAM=1 npm run dev
```

В mock-режиме форма показывает успех, но в Telegram ничего не уходит. Это удобно для проверки вёрстки и валидации.

ЮБ800
строгий знак

Строгий шрифтовой знак без дополнительных символов. Буквы Ю, Б, 8, 0 собраны в кривых по геометрии Futura / Nike Futura ND: круглые овалы, прямые стойки, плотный ритм. Это оригинальные векторные формы, а не файл шрифта.

Основной знак

Белый на графите. Без декора, без наклона, без дополнительных элементов.

Версии

Светлая, синяя и акцентная. В акцентной версии «800» — лайм или дорожка, «ЮБ» остаётся основным цветом.

Размеры

Геометрия

Nike Futura ND — проприетарный шрифт Nike.

Мы не встраиваем файл шрифта, а повторили его пластику в кривых: Ю, Б, 8, 0. Поэтому знак масштабируется без установленного шрифта. Если нужна точная копия — пришлите файл Nike Futura ND, заменим формы.

Правила

Охранное поле

Минимум 16 единиц (толщина основной стойки) вокруг слова. Ничего не заходит в поле.

Минимальный размер

70 px по ширине — только знак. Для шапки — от 120 px. Для печати — от 30 мм.

Не делать

Не растягивать, не наклонять, не менять трекинг, не добавлять тени и градиенты, не заменять шрифт без пересборки.

В шапке

Пример: знак 28 px по высоте, кнопка — лайм.

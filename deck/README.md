# Презентация ЮБ800

7 слайдов к встрече с Юрием Борзаковским. Тёмная тема, крупные цифры, без лишнего.

## Файлы

- `index.html` — презентация, открывается в браузере.
- `YB800-deck.pdf` — версия для отправки и печати, 7 страниц 1280×720.
- `onepager.html` — one-pager на A4 для встречи.
- `YB800-onepager.pdf` — one-pager для печати, 1 страница A4.

## Навигация

- Стрелки вниз/вправо, пробел — следующий слайд.
- Стрелки вверх/влево — предыдущий.
- Home / End — первый / последний.
- Кнопки в правом нижнем углу.

На мобильном слайды идут вертикально, кнопки скрыты.

## Слайды

1. Титул: ЮБ800, Москва, 21 ноября, пилот.
2. Возможность: имя, система, клуб.
3. Продукт: клуб, премиум, персоналка, пробная неделя.
4. Роль: 8–10 часов в месяц.
5. Экономика: 70 участников, 7,8 млн выручки, 2,8 млн прибыли, 7% роялти.
6. Дорожная карта: от встречи до 70 участников.
7. Предложение: пилот 3 месяца.

## Важно

- 23.10.2026 PDF пересобраны после замены локации на Москву. Экономика в деке и one-pager ещё старая (9 900 / 17 500 / 1 900 / 99 000 ₽, роялти 7%) — перед встречей обновить под модель 12 000 ₽ / 8 тренировок / 4 недели.
- Цифры — план и гипотеза, не гарантия. На слайде 5 это подписано.
- 1:42,47 — рекорд России на 800 м. 1:44,45 — время победы в финале Афин-2004.
- Имя и знак ЮБ800 используются только после письменного согласия Борзаковского.

## Пересобрать PDF

Откройте `index.html` в браузере или используйте Playwright со следующими параметрами:

- viewport: 1280×720;
- `printBackground: true`;
- `preferCSSPageSize: true`;
- margin: 0.

Playwright установлен в `~/.config/opencode/ux-kit`.

## «Сборная» — бизнес-презентация (28.10.2026)

- `Sbornaya-deck.html` — 20 слайдов 16:9: продукт, клиент, роль Юрия, тренер + помощник, команда, путь клиента, digital, привлечение, Telegram, партнёры, сборы, масштаб, экономика, доходы, план и решения.
- `Sbornaya-deck.pdf` — PDF для отправки и печати, 20 страниц.
- Формат — только текст и цифры, без фото и декоративных карточек. Один тезис и 2–5 цифр на слайд; детали остаются в устном комментарии.
- Экономика: этап 15 900 ₽ / 8 тренировок / 10–15 человек; тренер 5 000 ₽ + помощник 2 000 ₽ за тренировку; налоги 9%; аренда pass-through.
- 10 человек — пилот (вклад 43 690 ₽ за этап); 50 человек — 2,2 млн ₽ прибыли в год по плану.
- Telegram, партнёры и сборы показаны как дополнительные потоки и не заложены в базовый P&L.
- Это презентация-гипотеза: цифры плана не являются гарантией, ставки ролей фиксируются после первого потока.

### Пересобрать PDF

```bash
cd deck
NODE_PATH="$HOME/.config/opencode/ux-kit/node_modules" node - <<'JS'
const { chromium } = require('playwright');
(async()=>{
  const browser = await chromium.launch();
  const page = await browser.newPage({viewport:{width:1280,height:720}});
  await page.goto('file://' + process.cwd() + '/Sbornaya-deck.html');
  await page.evaluate(()=>document.fonts.ready);
  await page.pdf({path:'Sbornaya-deck.pdf', width:'1280px', height:'720px', printBackground:true, margin:{top:'0',right:'0',bottom:'0',left:'0'}, preferCSSPageSize:true});
  await browser.close();
})();
JS
```

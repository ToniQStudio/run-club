# Презентация ЮБ800

7 слайдов к встрече с Юрием Борзаковским. Тёмная тема, крупные цифры, без лишнего.

## Файлы

- `index.html` — презентация, открывается в браузере.
- `YB800-deck.pdf` — версия для отправки и печати, 7 страниц 1280×720.
- `onepager.html` — one-pager на A4 для встречи.
- `YB800-onepager.pdf` — one-pager для печати, 1 страница A4.

## Навигация

- Стрелки вниз/вправо, пробел — следующий слайд.
- Стрелки вверх/влево — предыдущий.
- Home / End — первый / последний.
- Кнопки в правом нижнем углу.

На мобильном слайды идут вертикально, кнопки скрыты.

## Слайды

1. Титул: ЮБ800, Лужники, 21 ноября, пилот.
2. Возможность: имя, система, клуб.
3. Продукт: клуб, премиум, персоналка, пробная неделя.
4. Роль: 8–10 часов в месяц.
5. Экономика: 70 участников, 7,8 млн выручки, 2,8 млн прибыли, 7% роялти.
6. Дорожная карта: от встречи до 70 участников.
7. Предложение: пилот 3 месяца.

## Важно

- Цифры — план и гипотеза, не гарантия. На слайде 5 это подписано.
- 1:42,47 — рекорд России на 800 м. 1:44,45 — время победы в финале Афин-2004.
- Имя и знак ЮБ800 используются только после письменного согласия Борзаковского.

## Пересобрать PDF

Откройте `index.html` в браузере или используйте Playwright со следующими параметрами:

- viewport: 1280×720;
- `printBackground: true`;
- `preferCSSPageSize: true`;
- margin: 0.

Playwright установлен в `~/.config/opencode/ux-kit`.

# AGENTS.md — ЮБ800

Этот файл читать **первым** при работе с репозиторием. Он задаёт контекст, правила и способ синхронизации между агентами и машинами.

## Что это за проект

**ЮБ800** — беговой клуб Юрия Борзаковского в Москве, Лужники. Первый год: 50–80 участников, бюджет до 300 тыс. ₽. Первая открытая пробежка — 21 ноября 2026, платные группы — с декабря.

Репозиторий приватный. Сайт **не опубликован**: GitHub Pages, Vercel и другие публичные деплои не подключены. Не включать публикацию без отдельного решения владельца.

## Локальный запуск сайта

```bash
cd landing
npm run dev
```

Сайт: `http://localhost:4173`. Dev-сервер слушает только `127.0.0.1` — не локальную сеть и не интернет.

Проверки (из `landing/README.md`):

```bash
html-validate index.html privacy.html
```

Плюс гейты из `~/.config/opencode/ux-kit`: `axe_audit`, `verify_overflow`, `verify_responsive`, `verify_target_size`, `lint_hardcodes`.

## Секреты

- `.env` и `.env.local` не коммитить.
- В репозитории допустим только `.env.example`.
- Токен Telegram-бота, chat_id, платёжные ключи и доступы к БД — в переменных окружения машины/Vercel, не в коде и не в чате.
- Не логировать токены и персональные данные заявок.

## Правила для двух агентов

Один файл — один владелец в момент времени. Если оба агента могут менять `landing/`, договоритесь, кто ведёт визуал, а кто — бота/контент.

1. Перед началом: `git pull --rebase`.
2. Работать в ветке `agent/<имя>/<задача>`, а не напрямую в `main`, если задача больше одной правки.
3. Маленькие коммиты с понятным сообщением; push после законченного шага.
4. Не делать force-push в `main`.
5. После смысловой правки обновить:
   - `PROJECT_STATE.md` — если изменился статус/блокер/next step;
   - `DECISIONS.md` — если принято новое решение;
   - `docs/journal/ГГГГ-ММ-ДД.md` — короткий итог сессии.
6. Перед передачей работы — обновить handoff и написать, что проверено, что не проверено и что осталось.
7. Не переписывать историю решений без явного запроса пользователя. Если решение отменяется — добавить новую запись в `DECISIONS.md`, а не молча удалять старую.

## Принципы дизайна

- Палитра: графит `#030712`, бумага `#F9FAFB`, лайм `#CCFF00`, дорожка `#1E5AA8`.
- Типографика: Jost (variable, self-hosted, OFL). В логотипе ЮБ — Jost 700, 800 — прежняя Futura-геометрия.
- В шапке — wordmark `landing/assets/logo-wordmark-dark.svg`; лайм; высота 14/16 px; подпись «беговой клуб» возвращена.
- Трек-эмблема `brand/logo-track-yb800.svg` — вторичный знак для соцсетей/мерча, не для шапки.
- Hero: фото на всю ширину, высота ограничена первым экраном; без градиента; eyebrow/lead/micro белые; CTA и микрокопия в текстовом блоке; «Афины-2004» у нижнего края фото.
- Лид в hero — 3 строки, пунктуация зафиксирована.
- Секции «Под вашу цель» и «Кто будет рядом» — фон `bg5.svg`, по ширине окна, с затуханием и `overflow: hidden`.
- Блок цифр: 6 фактов + примечание; без линий; серые вертикальные полоски; число и подпись по одной левой линии; плотные строки.
- Команда: не только Юрий и тренеры, но и методисты, врачи, массажисты, поддержка, специалисты и комьюнити по интересам.
